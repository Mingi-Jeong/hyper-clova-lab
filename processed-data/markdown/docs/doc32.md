1. 부담금 입금 당일 디 폴트옵션으로 자동매수 되었습니다. 2주간의 대기 기간이 <mark>적</mark> 용되는 것 아닌가요? 2. 예 금상품 만기 당일 디 폴트옵션으로 자동<sup>매수되었습니다.6주간의대기기간</sup> 이 적용되는 것 아닌가요? 

> - 신규가입자의 최초 부담금 입금 후 2주 대기 기 간이 경과하면 지정한 디폴트옵션으로 자동매수되며, 이후 입 금되는 부담금은 즉시 지정한 디 폴트옵션으로 자 동<sup>매수됩니다.</sup> - 만기 형 상품의 만기상환일 이후 6주 대기 기간이 경 과하면 지정한 디폴트옵션으로 자동매수되며, 이후 동일한상품 만기 시 만기 상환 처리즉시 지정한 디 폴트옵션 으로 자동<sup>매수됩니다.</sup> 

160 <mark>] 0-13 |</mark> 디폴 트옵션 을 지 정 하면, 기 존 에 보유 중이 거나 특정 상품 을 매도한 후 발생한 현금성 자산도디 폴트옵 션으로자동 매수 되나요? 

- 아니요. 신규 가입자의 부담금 , 만기형 상품의 상환시에만 디폴트옵션 자동매수 가 적용 됩니다. 



예 금만기 일 에 디폴트옵션 을 지 정하였습니다. 예금 만기상환 후 디 폴 트옵션 으로 자동 매수 되나요? 

- 디 폴트옵션지정 전 상환된 예금은 디폴트옵션 적용 대상이 아니며, 지정이후 상환분에 대해서만 디폴트옵션자동매수가 적용 됩니다.
