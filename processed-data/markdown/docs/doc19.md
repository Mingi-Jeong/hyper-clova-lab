퇴직연금(DC/IRP) 과세재원확정 

- 1.재원확정이란? 

금융기관의 연금계좌 과세대상금액과 국세청 소득·세액공제합계액을 확인하여 국세청 합계액을 초과하는 과세대상금액을 과세제외함으로써 과세대상금액을 일치시켜주는 업무입니다. 

전금융기관 연금과세대상금액 – 국세청 소득·세액공제합계액 = 과세제외가능금액 *MIN(과세제외 가능금액, 계좌의 과세대상금액) 

- 2.재원확정 필요서류 

-연금보험료등 소득·세액공제확인서(국세청자료)
