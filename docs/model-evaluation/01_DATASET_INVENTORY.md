## 3. 구조화 정답셋

### 3.1 디폴트옵션 FAQ 100건

파일: `datasets/default_option_faq_100.csv`

| 필드 | 평가 용도 |
|---|---|
| ID | 샘플 식별자 |
| 카테고리 | 층화 표본 및 카테고리별 성능 |
| 대표질문 | 정규 질의 |
| 유사질문표현 | paraphrase robustness |
| 표준답변 | 의미 정확도 gold answer |
| AI분기포인트 | 필수 개념/키워드 recall |
| 근거구분 | 출처 유형 검증 |
| 근거ID | citation correctness |

**권장 케이스 수**

- 대표질문: 100건
- 유사표현: 각 행에서 최소 2개를 분리하여 200건
- 부정·경계 변형: 각 행당 1개를 추가 생성 후 전문가 검수하여 100건
- 최종 목표: **400건**

### 3.2 디폴트옵션 출처 9건

## 4. 비정형 문서 평가셋

### 4.1 연금·퇴직연금 업무 문서 58개

각 문서에서 아래 3개 유형을 1건씩 만들면 최소 **174건**입니다.

- 단일 근거 사실형 58건
- 다중 문단 결합형 58건
- 예외·조건·기준일형 58건

추가 권장:

- 답 없음(unanswerable): 30건
- 문서 간 충돌/기준일 차이: 30건
- 고객 친화적 재설명: 30건

### 4.2 투자설명서 100개

각 상품마다 3문항을 구성해 **300건**을 확보합니다.

1. 상품 기본정보 또는 운용전략
2. 위험등급·핵심 투자위험
3. 보수·수수료·환매·과세 중 하나

교차 상품 비교 50건을 추가하여 총 **350건**을 권장합니다.

## 5. 평가 데이터 분할

| Split | 비율 | 역할 |
|---|---:|---|
| Development | 20% | 프롬프트·청킹·검색 파라미터 조정 |
| Validation | 20% | 후보 설정 선택, 임계값 결정 |
| Test | 60% | 최종 모델 비교; 설정 확정 후 공개 |

주의:

- 동일 FAQ의 대표질문과 유사표현이 서로 다른 split에 섞이지 않도록 `ID` 단위로 그룹 분할합니다.
- 동일 투자설명서에서 나온 문항도 문서 단위로 그룹 분할합니다.
- 테스트 정답을 system prompt나 few-shot 예시에 사용하지 않습니다.

## 6. 데이터 품질 리스크

| 리스크 | 영향 | 통제 방법 |
|---|---|---|
| OCR 띄어쓰기·문자 오류 | 검색 누락, 오답 | 원본 이미지 확인 플래그 |
| 표 셀 평탄화 | 숫자-항목 연결 오류 | 표 전용 파서/비전 비교 |
| 규정·세법 기준일 | 시점 환각 | 문서 기준일 메타데이터 + 최신성 경고 |
| FAQ 내부 수정 흔적 | gold answer 모호성 | 검수 상태/version 필드 추가 |
| 동일 문서 SHA, 다른 상품코드 | 잘못된 dedup | 상품코드를 독립 ID로 유지 |
| 평가셋과 RAG corpus 동일 출처 | 과대평가 | 문서 홀드아웃과 질의 홀드아웃 병행 |
